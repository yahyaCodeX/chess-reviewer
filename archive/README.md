# Archive

## spring-boot-gateway

The original **Spring Boot** gateway (Java 17). It was the first version of the
API layer and has been replaced by the **FastAPI** gateway in
[`FastApi-Backend/`](../FastApi-Backend), which adds game tracking,
de-duplication, rate limiting, queue positions, share links and the
stuck-game watchdog.

It is kept for reference only and is **not maintained** — it does not support
those newer endpoints, and the current frontend expects them.
