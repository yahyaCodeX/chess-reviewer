# Sounds

Real recordings, all released under **CC0** (public domain) on
[Freesound](https://freesound.org). Every sound is listed in
[`src/lib/soundConfig.js`](../../src/lib/soundConfig.js). To change one, replace
its file here (same name) or point the config at another file or URL you have
the rights to use. A missing file is simply skipped.

Each file was trimmed to start on the hit, cut short and level-matched; a few are
two recordings layered together (noted below).
